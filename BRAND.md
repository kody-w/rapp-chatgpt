# RAPP brand

## Promise
**AI agents anyone can use.** Describe a task in the assistant you already use; RAPP builds the agent, checks it, and runs it on your own data. Nothing to install.

## Names
| Use | Name |
|---|---|
| Umbrella brand | **RAPP** (never "RAPP/1" in prose; it stands for Rapid Agent Prototype Platform, rarely spelled out) |
| Build an agent | **RAPP Agent Builder** |
| Find an agent | **RAR Agent Finder** (RAR = the RAPP Agent Registry) |
| Verified world numbers | **DOGG World Check** |
| Run agents on your own computer | **RAPP Brainstem** (free; always the optional last step, never the first thing a new person hears) |
| Company | Wildhaven Homes LLC |

## Voice
- Plain business words. Say what it does for the person, not how it works.
- Lead with using it now. "Install" and "Brainstem" come last, if at all.
- No hype verbs (elevate, unleash, seamless, revolutionize). No em-dashes.
- Honest about limits: "it applied the agent's rules" when it didn't run the file; "for information only" on world numbers.
- Never ™ in body copy.

- Show the real product: screenshots and recordings from ChatGPT, never mock-ups.
