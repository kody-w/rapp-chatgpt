Turn any idea into an AI agent

Describe a task in ChatGPT, or paste a meeting transcript. RAPP Agent Builder hands you a working agent in one file that you can run on your own computer.

How it works

  1. In ChatGPT, open RAPP Agent Builder and say what you want the agent to do.
  2. ChatGPT checks whether one already exists in the public agent registry, or writes a new one and checks it.
  3. Save the file and run it with the free RAPP Brainstem.

Run your agent

Mac or Linux, in Terminal:
curl -fsSL https://kody-w.github.io/rapp-installer/install.sh | bash

Windows, in PowerShell:
irm https://raw.githubusercontent.com/kody-w/rapp-installer/main/install.ps1 | iex

Put the agent file in the Brainstem's agents folder, open http://localhost:7071, and ask.
